## Shared nodes

### Mandatory

| Node | Effect |
|---|---|
| Ability 1 | Grants A1. **Root or join, never a branch.** Training-wheels exclusive does NOT sit right after this, since A1 should be one of the first, and removing training wheels is obviously not a beginner-focused node. |
| Ability 2 | Join / capstone. Grants A2. |

### Nonexclusive

| Node | Effect |
|---|---|
| +HP | +5 max HP per rank (3) |
| XP | Higher XP gain |
| Collector | Unseen events/items more often |
| Unseen weight | Unseen cards of this character appear more |
| Cheaper unlocks | Outfit / common relic costs less in shop |
| T1 buffer | On turn 1: 5 tHP / 5 heal / 5 soothe (pick flavor on the character) |
| First cleanse | First debuff on this character each combat is removed |
| Reroll | +1 reward reroll per run |
| Card banishes | Banishes to strike cards off the offer pools |
| Starting gold | +5 gold at run start while in party (3) |
| Rest upgrade | Unlocks extra rest-site options (see Rest Site Upgrades) |
| Replace agg | One aggressive basic → random common of this character, at run start (3) (If there aren't enough, the third rank doesn't do anything, that's ok - noodle) |
| Replace def | Same for one defensive basic (3) |
| Extra outfit cards | Doubles the number of cards the worn outfit adds to the starting deck |

### Exclusive families (every character)

| Group | Shape |
|---|---|
| Aggressive starter | 3 ranked paths. One chosen. |
| Defensive starter | 3 paths. Each adds a different choose-one. Cinder has no Exclusive D — front vs back is already the choice; her def is a single upgrade. |
| Training wheels | 3 paths. Not mandatory. Each **removes the enable**: A1 no longer fuels the mechanic; it becomes a situational payoff. She now has to get that fuel from cards. |
| Opening card/energy | +1 card drawn and -1 energy on turn 1, or opposite. Not mandatory. |
| Bounty | Elite/boss: extra gold or +1 card reward |
| Shop | −10% prices or +1 slot |
| Rest efficiency | Rest sites heal more, or do one additional action each rest site |
| +Agg / −Agg | Add or remove a copy of the aggressive basic |
| +Def / −Def | Add or remove a copy of the defensive basic |
