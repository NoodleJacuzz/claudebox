# NODES-LIST — condensed master node list

One flat, scannable list of every progression node idea, with the scattered per-character "Nonexclusive
extras" pulled up into their character block and the PROGRESSION-LIST entries that were never folded
into STARTER-LIST added. Built for keeping open while laying out a skeleton.

**This is a reference, not a decision.** `../starters/STARTER-LIST.md` stays the authority on node content;
`PROGRESSION-LIST.md` on topology. Sources: **[SL]** `../starters/STARTER-LIST.md` · **[PL]**
`PROGRESSION-LIST.md` · **[SR]** `../STARTER-REWORK-01.md` · **[BB]** character bible
`../../designBibles/characters.md` §"The Meta-Progression Design Space".

Rank column: `×N` = one ranked node bought N times (unless noted, each rank is one path of a family).

## D. Rest Site Upgrades

**Status (session 26): every option below is built.** Each is a row in `honeycomb.restOptionArray`
(`honeycomb-content-map.js`); the campfire builds its menu from the party's selected Rest1/Rest2 nodes,
and Rest-A adds an action while Rest-B raises Sleep's heal. Per-character assignments and the four
unassigned options are in `SKELETON-MAPPING.md` §5. The **Rest Lab** debug tool opens a campfire with
every option and 100 actions.

- **Tend** (the broken-only campfire choice) was REMOVED — poorly balanced and confusing.
- **Duplicate** is built but must stay UNASSIGNED until it is rebalanced; no shipped Rest node names it.

Unlocked by the **Rest upgrade** node. 

| Option | Effect |
|---|---|
| Exercise | each party member gains XP |
| Fortune Telling | replace a starter with a random common or rare of that character |
| Treatment | heal a chosen ally by double the rest rate |
| Scavenge | +25 gold |
| Purge | remove a card, cheaper than the shop (currently default; keep) |
| Gamble | transform a non-starter into a same-rarity card for the same character |
| Laundry | exhaust all junk currently in the deck |
| Preptime | characters gain half the rest rate as tHP for the next battle |
| Duplicate | pick a card and copy it (too strong — should be a shop option) |
| Mail order | trigger the shop; prices are doubled |
| Journal | view 3 random droppable cards you don't own; pick one to double its odds in rewards/shops |

Note: cannot upgrade starter cards. **Outfit-signature cards should be allowed, they just don't upgrade infinitely, but the player might add a second copy of their outfit card through a node and want to upgrade them**

## F. Idea bank — design-space levers not yet a named node

From **[BB]** §0–7. Some are already the per-character "Extras" above; the rest are unwritten node
candidates. Check **[SR]** §2 before turning any into a node.

- **Deck/draft:** Banishes *(not a node)* · Rare‑card weighting · Card banishes *(= Banish)*
- **Early combat:** Innate assignment *(dropped — 5-card start)* · Health padding *(survive-lethal is not a node)* · Early status cleanses *(= First cleanse)*
- **Economy:** Capital injection *(= Starting gold)* · Bounty multipliers *(= Bounty)* · Shop restock / extra slots *(= Shop)*
- **Friction:** Retaliation dampening *(e.g. Brienne −1 thorns)* · Deck-clog resistance *(e.g. Nettle/Cassadora first junk exhausts)* · Position lock · Status decay
- **Friction reversal:** Punishment-as-reward · Deck-clog tolerance · Tax transformation *(outfit or exclusive node)*
- **Synergy:** Status application boosts · Cross-party hand-off efficiency · Resource refunds *(not a node)* · Engine scaling *(not a node)*
- **Growth:** Content unlocks *(outfit)* · Collector's boon *(= Collector)* · Growth rate *(= XP)* · Ease of sub-goals *(= Cheaper unlocks)* · Weight Training *(relic)*
