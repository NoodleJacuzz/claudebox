# rework/ — folder map

This folder holds the four content pathways that rebuild what the MVP shipped with. **Open one
subfolder, not this folder.** Each has its own catch-up carrying that pathway's last session, its
files and its remaining goals.

| Subfolder | Pathway | Start at |
|---|---|---|
| `cards/` | The card pool: what cards cost, what they do, how many there are, which are cut. Also the balance model every price comes from. | `cards/CATCH-UP.md` |
| `progression/` | The six per-character trees: nodes, EXP costs, what each node does. | `progression/CATCH-UP.md` |
| `enemies/` | Enemy numbers, identities, roles, encounter composition. | `enemies/CATCH-UP.md` |
| `starters/` | Starting decks, alternate outfits, relics and heirlooms. | `starters/CATCH-UP.md` |

Two files sit at this level because more than one pathway reads them:

| File | Holds |
|---|---|
| `STARTER-REWORK-01.md` | The umbrella brief, Noodle's quotes verbatim — starters, outfits, relics and the progression levers. It wins over any annotation. |
| `AUDIT-01.md` | The session-30 audit, **open findings only**. Fixed findings are `../Archive/AUDIT-01-DONE.md`. |
