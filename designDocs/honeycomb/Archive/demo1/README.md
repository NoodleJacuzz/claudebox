# The first demo's documentation tree, frozen 2026-09-25

**Nothing routinely reads this folder.** It is `!designDocs/honeycomb/` exactly as it stood on
2026-09-25, when the first demo had shipped as the Public Test Release and Noodle set the second demo's
gate: every workstream folder at its old path, every `CATCH-UP.md` and `FEEDBACK.md`, every `_archive/`,
the old root `BASICS.md`, `CATCH-UP.md` and `FEEDBACK.md`, and the old `Archive/` under `Archive/`.

The live tree was rebuilt the same day from Noodle's pipelines: one document per pipeline
(`../../card_pool/CARD-POOL.md`, `enemies/ENEMIES.md`, `art_pipeline/ART-PIPELINE.md`, `events/EVENTS.md`,
`mobile/MOBILE.md`, `relics/RELICS.md`, `engine/ENGINE.md`, `tooling/TOOLING.md`) plus `desk/`. Every OPEN
item was carried into those documents in his words, and the briefs still in use were moved beside them.
What is here is what was not carried: closed items, finished briefs, superseded designs, and the folders
for work that is off the second demo's gate (`chessmaster/`, `gallery/`, `card_redesign/`).

Relative links inside these files point at the old tree and are not maintained. If a question of the form
"why is it like this" or "when did that change" comes up, this is where the answer is; grep it rather
than reading it.

`chessmaster/` is on Noodle's machine and not in the cloud copy; it belongs here too.
