THE RULES THE BOT USED
  Which stop to walk to: every stop is scored by its type, and a path is the sum of its stops. The weights are:
    combat   base 1
    elite    base 1.5; 2.5 extra while the party is at 70% health or more, -4 when it is below
    event    base 0.6
    treasure base 2
    rest     base 0.3; 8 for each whole party's-worth of missing health
    shop     base 0.3; 2.5 extra with 90 gold or more
    boss     base 0
  What to take, buy, remove or choose: the learned bot takes the option with the best value it has measured, if that value is above zero,
  and decides 15% of everything at random so its values keep updating. An option seen fewer than 12 times has no trusted value and is decided at random.
  A run is judged by how many more fights it won after the decision, plus 6 for finishing the run.
  The bot deciding here: the learned bot, using !designDocs\honeycomb\tools\balance\results\2026-09-21-first\values.json.
